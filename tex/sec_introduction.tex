\subsection{Introduction}
\label{subsec:introduction}

BiteBound is an interactive labyrinth game that leverages the Waveshare ESP32-S3-Touch-LCD-1.69 development board to create a physical, tilt-controlled gaming device using an onboard inertial measurement unit (IMU).
By combining a real-time embedded physics simulation with secure network communication via the Message Queuing Telemetry Transport (MQTT) protocol, BiteBound establishes a complete Internet of Things (IoT) ecosystem.
This setup connects physical hardware interactions with digital dashboards on Android and web to enable real-time telemetry streaming, remote configuration, and external visualization.

\subsection{Mission Statement}
\label{subsec:mission_statement}

The primary objective of the BiteBound project is to build a responsive, low-latency gaming system that demonstrates effective multi-core task scheduling on resource-constrained hardware.
Utilizing a playful, bakery-themed design, the gameplay challenges players to navigate a virtual cherry (ball) through procedural mazes or flatland to collect cookies.
A key technical focus is maintaining a stable, high-frame-rate rendering pipeline on the device while concurrently handling bi-directional network transmission via MQTT.
To support this goal, the project aims to deliver a native Kotlin-based Android application and a web-based Node-RED operator dashboard, providing a seamless multi-platform experience.
