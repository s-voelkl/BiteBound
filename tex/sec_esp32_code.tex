\section{ESP32 Code}
\label{sec:esp32_code}
The main control logic for the ESP32 microcontroller, including the core game loop,
hardware abstraction, and network communication, is presented in this section.

As the requirements state that the ESP32 code should be part of the appendix,
the code listings are included here for reference.
% Though, only the header files and the main sketch file are included, as they contain
% the essential logic and configuration for the project.
% The cpp files are omitted, as they would be too long to include in the appendix and
% are not necessary for understanding the main logic of the project.
